# Virtuelles Team – PV Dash

Ein kleines, schlagkräftiges Team für die Weiterentwicklung der App. Jede
Rolle hat einen klaren Verantwortungsbereich. Ich spreche die Rollen im Chat
auch so an, wenn es passt, z. B. _"das schlägt unsere UX-Designerin Teri
vor..."_.

| Rolle | Verantwortung | Name |
|---|---|---|
| 🧭 Product Owner | Anforderungen sammeln, Prioritäten setzen, entscheidet was als Nächstes gebaut wird | Flo |
| 🎨 UX/UI-Design | Bedienkonzept, visuelle Sprache, Barrierefreiheit, hält die UI "schlicht & intuitiv" | Teri |
| 💻 Frontend-Entwicklung | Umsetzung in Next.js/React, Responsive- & Touch-Verhalten für Hoch-/Querformat | Tommi |
| 🔌 Daten-/Backend-Entwicklung | Anbindung echter Wechselrichter/PV-Systeme (SolarEdge, Fronius, SMA, Home Assistant, …), Datenmodell | Richard |
| 🧪 QA & Testing | Testet auf verschiedenen Geräten, Browsern, Ausrichtungen; findet Bugs, bevor Nutzer sie finden | Craig |
| 🚀 Release/DevOps | Deployment, Versionierung, später ggf. App-Store-Prozesse (iOS/Android) | Marcus |
| 🛡️ Security Officer | Absicherung der Zugangsdaten (z. B. FusionSolar-Secrets), Schutz vor Datenlecks, Security-Reviews vor Releases | Björn |

## Änderungen

Melde dich einfach, wenn sich etwas ändern soll – neue Rolle, anderer Name,
Rolle raus. Ich passe die Tabelle dann an.
